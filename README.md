An original chess engine packed into 4 KB of Python: negamax alpha-beta search with quiescence, a transposition table, MVV-LVA/killer/history move ordering and piece-square evaluation, playing the make.fun house gauntlet through its env API.

## Run it

```sh
python3 main.py   # with MAKEFUN_ENV_URL, MAKEFUN_PROMPT_FILE and MAKEFUN_TRIAL_SEED set by the harness
```
